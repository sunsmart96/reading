吴思这个人提出了潜规则，血酬定律。我觉得很有意思，就买了他的几本书。

这本书不是专门写的而是整理他的一些访谈记录。我在之前已经读过他的一些作品。整体来讲是一个有水平和认识的人。我看他的书是想了解中国的社会现实到底是怎么回事。

由于这本书是访谈录，我就写一些里面零散的感兴趣的内容。

# 1.理论的地基要打到单细胞生物
这篇的综合论述观点认为，要从生物学上获得更基础的社会认识的地基。最简单的生物也有了最本质的行为，人在这一点上没有区别。他认为单细胞生物最根本的行为准则就是趋利避害。作者年轻的时候经历过前30年的洗礼，而且在成长的最关键时期，就是在那个十年度过的。而采访是在21世纪初期，他认为年轻时被灌输的思想是算是走了弯路。坦率来讲，我也认为共产党那套经典叙事荒诞而无用，没有逻辑，充满暴力。甚至发展到一定程度，他们自己的精英都不信。只是已经处于那个位置，公开的否定会损害他们的既得利益。

所以作为全书最基础的篇章，人活着到底是为了什么？最根本指导我们行为的原则应该是什么？想爽，怕死

我读他的书并不指望可以获得什么终极奥义，只是想了解中国，了解中国的现实，让我更容易发展，而不是受困与一些被灌输的思想进而限制自己的发展。在这一点上我觉得他写的很好。

如果一些行当付出的少获得的多，人们就会蜂拥而至，比如当官。如果义务特别多而权利特别少，那就被被压迫的阶级。谁说的算，暴力最强者说的算。

中国跟西方国家不同的一点在于当地的官员任命是由更高级别的官员授权得到的，而不是民众选举。比如美国州长不是总统任命的，而是各个州自己选举的。因此中国的政治逻辑跟欧美民主社会差异很大，与之配套的行政司法立法体系也存在根本性不同。中国是中央集权，对于联邦制，中国的史书命名是军阀割据，不是一个好词。毕竟修编正史的人都是国家中央的官员，他们怎么敢写颂扬地方相对独立的叙事逻辑。当今世界在广大的亚洲非洲不发达的确，依然大量存在这种社会形态。我认为这是一种落后的形态。因为这意味者所谓国家本质上仍然掌握在少数高级官员手中，他们可以直接任命地方官员，地方官员对权力来源负责，民众没有足够的权益对抗官僚集团，只是单纯的被统治者。

还有一点是道德的力量只是小部分力量。不能把道德当成决定性力量。我曾经就在这个上面吃了亏。我曾经觉得做事情就应该光明伟岸，就应该基本按照共享分配收入。可实际上真正有影响力的往往就是个别人，是他想怎么给你就怎么给你，想不给你就不给你。没有什么善有善报恶有恶报的关系。自己秉持的那些儒家推崇的行为，并不能获得合理的回报。在这里就用错了道德的力量。现在想想也是，如果道德真那么有用，乱臣贼子篡位的时候绝大多数人都觉得不对不照样逼汉献帝退位。所以对待官员，不能先天性低就认为官员是好人好官，那是非常稀有的。

所以归根到底一句话，活着就是争利。

# 2.元规则理论的根基：生命换资源的原始策略
这里面讲了一些如何对待史书的观点。作者认为正史就像是一份行政地图，如果用这种地图找吃饭喝水的地方就会饿死。每个人读历史都有自己的目的，有一些东西就不会明晃晃放在正史中写，但这些东西实际又很重要，这就需要一些另外的视角，把被掩盖的内容挖掘出来。

比如说天赋人权，是这样吗？又无缘无故的平等协商嘛？不存在的。中国历代都是皇家贵族打江山坐江山，甚至把江河矿产变成他们所有的。现在的红色贵族不也是如此嘛！没有本质区别。

很多基层的官员，欺压底层百姓，但是还在场面上说漂亮话，因为只要不讲理有利可图，不遭报应。被欺压一方缺乏反制手段，告状无门。而拥有合法伤害权力的人可以借用公共权力谋私，个人可以获得好处却不用承担成本。所以公共的法规成了摆设，实际运行的是潜规则，不放在台面上。

同样的，人的生命在宣传中总是说无价的，因为任何人都觉得自己生命无价。可是在市场上这是真的嘛？会无限制给人用药嘛？会无限制给人赔付嘛？不存在的。你能支付的水平就是你生命的价格。

唱高调不能解决实际问题！更不要相信唱高调的内容！

# 3.从潜规则到血酬定律再到元规则
如果选择一个最基本的规则，作为其他规则的基础，就是暴力最强的人说的算。

# 4.官家主义这个词
中国历史书中对秦及以后的朝代定义是封建，可是真正的封建是秦之前的形态。从秦国开始的是中央集权，作者提炼了一个新的概念叫做官家主义，很贴切，就是官员主宰一切。可以尽可能减小潜规则在官场大行其道的路线就是实行民主，让权力真正来自于民众，给新闻界松绑，可以自由报道官员的劣迹，而不是让官方审核媒体出版内容。可是这个事情很难推行。毛泽东在刚打下江山的时候自认为可以解决，可是他自己都不愿意放弃权力，直到死。没有形成真正的民主制度。在这种条件下的中国，想发展起来企业，就一定要官商勾结，收买官员，否则压根发展不起来。甚至想法办你随时办你，因为你想做出点有突破的东西，早就被恶法限制住了，不给好处就办你，给好处就睁只眼闭只眼。这在过去中国40年都是如此。

另外作者认为应该对自由研究结果宽松一些，不要因为一些言论就对发表的人喊打喊杀，这样不利于形成正确地认识，最终把民族带向深渊。

# 5.官家主义和血酬史观
官家主义用来描述资本主义之前的社会状态。从最近几十年全世界的发展来看，大量经济落后的确的社会制度也更倾向暴力集团统治，民主制度极度欠缺。而经济比较发达的地区，民主制度更加完善。甚至有一些国家在经济发展起来后又倒退，原因之一就是法制民主制度跟不上。

# 6.构建血酬史观
当前中国限制民间资本进入金融业，最近这两年明显限制外资。国家不断把矿回收，实现官方垄断。官进民退。曾经香港是最自由的贸易港，现在也不是了。以前有福利房，可以用远低于市场价的价格买房子。这是一种行政权力干涉市场行为。但是这种甚至更严重的，依然在中国大行其道，甚至越来越严重。目前中国没有独立的司法体系，没有开放的媒体，这个经常上网的人都知道。人大代表更不会代表人民。台湾经历过类似的，解决办法就是解除报禁，可以让媒体更加自由报道官员问题，来制衡政府权力。

官家垄断国家的核心资源，其实肥的只是很少一部分人。并没有实现真正的公有化。

所谓史观，我觉得就是共产主义意识形态叙事的一种名词，本质上就是站在什么角度看待历史。

# 7.重建对中国历史的理解
对于暴力，往往主流宣传都是反暴力，可是这些所谓的主流本身就是依赖最强大的暴力支持才成为主流的。所以我想发展自身的实力，归根到底要发展暴力。暴力越强大话语权越重。

# 8.基本概念出了问题
他认为共产主义意识形态中的历史唯物主义阶级等概念不能解释古代中国的一些问题。如果最基础的概念都不正确，构建的理论体系必然是不稳固的。

# 9.命名是认识世界的手段
体制内的一些研究，由于钱是从上面拨下来的，所以很多时候研究本身就会受到限制，总不能把饭碗砸了。官僚集团并没有像声称的那样，服务人民。

# 10.历史与公正计算
改革开放几十年的成果，本质就是提高民众的自由。弱势方想在博弈中获得更多的好处，就要有能力制造更大的成本威胁。作为统治者想要控制民众的公平感，就要控制信息的传播。组织起来的工会是保护劳动者权益的重要手段。否则个人很难对抗组织。通过宪政，民主，来制衡统治集团，对社会有好处，对统治集团自身维护统治也有好处。这是一种长远发展的好处。官僚集团一定是不愿意被民众监督的，所以依赖朱元璋或者毛泽东这种个别强势领袖来支持民众对抗官僚集团往往都是人亡政息。官僚集团内部一旦失去制约成势，积重难返，就意味着新的王朝更替开始。

社会结构会对社会治理形态产生重要影响，如果中国绝大多数人都是农民，这种环境下不可能建立真正的民主制度。我认为这是孙中山或者资产阶级革命最终在中国失败的根本原因，那个时候的中国农民占了绝大多数，甚至都不识字。这么大的群体没有能力认识甚至左右民主制度。所以共产党当年夺权的策略站在夺权的角度是非常正确的。直到现在中国仍然有接近一半的农村人口。大部门城市人口也是最近30年进城的农民，在这种情况下，资产阶级的变革力量仍不充分。

好的一点是，伴随中国老龄化，未来三十年会有几亿的低端人口消失，而年轻人中大部分都会接受高等教育。从这个角度来讲，中国的民主发展不在当下，而在15年后。 

# 11.局观历史
对局的局，用对局的观念看历史，就类似于博弈论，中央与地方的博弈，统治者与被统治者之间博弈来分析和解释历史。凭什么打江山的人说的算？凭什么他们可以制定法律？因为血酬定律。

# 12.规则本身就是博弈结果
暴力统治集团没有办法随心所欲，他们所制定的规则就是博弈的结果。是统治者与被统治者之间博弈的结果。

# 13.拆解人间对局：潜规则的系列概念
这篇很长很杂。主要讲了一个故事，就是警察可以通过说居民窝藏盗贼把人刑拘。这对于警察代价很小，但是对于普通人不仅没法出去赚钱，搞不好在里面还会挨饿被打。原因就是这些警察需要额外收入。所以一个村子一般跟警察协商定期交点保护费免得被没完没了找事讹诈。这样协商好效率高一点。故事是古代，可是每天都发生在我们身边。比如交警就经常用这招创收，各种政府部门都是如此。而且书里面讲古代的集成官员其实编制很少，但是真正运行需要更多的人，这时候县令就自己花钱雇佣，这些人不可能只依靠县令的工资养活，这时候就要出去欺压百姓获取额外收入。在其中的一员即使想对百姓好也很难，因为如果对百姓好就是跟长官和同僚为敌，自己在体制内绝对没法混。如果想和周围打成一片，就得欺压百姓。百姓也看的清楚，既然这个群体这么爽，他们也想方设法加入，导致官僚群体膨胀，需要压榨更多的百姓，最后整个社会崩溃。当前的中国也是如此，祸根已经埋下并且开始起作用。现在全国到处都在扩编辅警，这帮辅警就是黑社会。老百姓要么死要么造反，选择不多。

# 14.历史对局的终极法则
个人在很小的范围内应该尽量维护道德。因为在那个范围内，严重破坏道德会很快遭到打击。可是在经商或者做官，要相反而行，否则无法生存。社会如果充斥潜规则，则社会会走向毁灭。在当下的中国，依然极其广泛存在合法性破坏，当官的说的算，说给你就给你，说剥夺就剥夺，不顺心就给你开罚单。西方社会不是说没有，而是有一套比较放的上台面的流程和博弈方法，大家按规矩来。

# 15.我的写法就是破局之法
公有和私有之争不能等同于资产阶级和无产阶级之争。共产主义的叙事我觉得不能解决很多实际问题，是一种落伍的理论。作者认为中国会走向民主化，在一两代人的时间。可是现在正是这个时间，整个社会在开倒车。

# 16.老子曲线
主要结合实际讲了一些对老子的理解。官方给民众的自由度在比较低的时候提高自由度可以让民众和官方都获得发展机会。但是到了一定限度之后，民众的需求就会从经济变为知情权，监督权，选举权，到了这个阶段既得利益统治集团的利益开始跟民众的利益相悖。我觉得当下的中国就是如此，很多十几年前非常开放的事情现在都变得封闭了。

人如果只关注自身吃饱穿暖，那就是牛马，是统治者喜欢的，因为没有更高级的欲望。一旦有了高级欲望，就会要求某些政治权力，监督权，知情权，获得掌握更多的知识，掌握自己的命运。一旦人愿意干什么就干什么，居于统治地位的统治者权力就丧失了。这是他们不愿意看到的，他们所谓的权力就是让大众想做什么事必须请求于他们。还有就是之前发展那部分的自由和经济保障，不论是民众得到的，还是官方得到的，都没有保障，都可能失去。这是在20年前做的判断，以目前的局势来说的确如此。很有远见。

# 17.儒家与自由主义是可以调和的
儒家不能完全代表中国的传统文化。而且在古代并不是儒家足够强势以致成为主流思想，而是官家决定的。儒家的观点，哪些需要大力宣传用于维护自己统治，哪些需要避免宣传来维护自己利益都是有官家决定的。比如忠君爱国那套就被官家大力宣传，而是孟子民为重社稷次之君为轻就被朱元璋删了。所以儒学从来都不是依靠自己多么的不可替代发展的，而是受到官方决定的。

另外所谓的精神家园，信仰，也只是少数精英的部分需求，对于绝大部分人重要的是如何生存下去。儒家的一部分观点在当下的确不合理，但也有一部分观点是合理的。新自由主义也一样，更关注自由民主，用民众的力量对统治者进行反制，所以二者存在共存和融合的来满足新时代需求的基础。

# 18.《中庸》可以和自由主义接轨
我觉得没必要强行把一些传统思想跟现代的思想融合，不行就废掉不用。

# 19.谎言的成本和收益
中国从古至今的政治体制就是说谎收益很高，所以体制内非常容易看到说一些自己都不信的话。每个人都是表演者，当然不止局限于体制内，在很多公司也是如此的。最近十几年抓的贪官非常多了，基本都是被抓前几天还在会议上说一些道貌岸然的话，被抓后公布罪行都是跟公共场合说的话相反的事情。反差极大。 

# 20.我对几个基本概念的理解
写了很长，首先劳动并不跟人性相悖。在一定范围内，人愿意游泳跑步做一些事情，相反什么都不做才是人受不了的。每个人一天活动一两个小时是愉悦的。人也有七情六欲，应该尊重人的基本欲望。三年自然灾害这个名字看起来是自然问题，实际是人祸。这个事情就是毛泽东治国的错误，但是却不敢明确指责他。刘少奇在庐山会议指责他就被收拾了。

# 21.黑窑事件与地霸经济
黑煤窑我觉得仅仅通过民主化也不一定能解决好。因为当地的官员和商人从中获利太大，就算是劳工，也是对这份工作有需求的。只不过伴随着发展，劳工的待遇会有所提升。这是一个反复博弈的过程。给与媒体更大的自由是好的，可问题是媒体也可能会被收买，比如当地的媒体就受到管控不会发声。当地集团的利益跟中央是存在矛盾的，可是中央并没有太大的动力去改变，只是出了问题打击一下。当地的经济就靠这么，你都给封了，就农业那点收入够干什么呢？只有到了一定程度，产能严重过剩，开始进行淘汰，加上成本逐步提升，这么干冒的风险大收益，性价比没有那么高才有可能好转。地方对于中央的命令也不是不大折扣地执行，存在博弈，推脱、阻挠、刁难非常常见。基层劳工的薪资实在是太低了，提升一些到底会不会影响企业发展？对于很多纯粹压榨廉价劳动力的企业就是如此，可问题是赚的钱也是跑到老板可官员手中，并没有激发劳工的积极性。而且不利于企业创新发展，甚至这些企业压根就没有做大做强的想法。可是发展经济的根本目的是什么？是用过压榨底层人的血汗来富了上面人还是让大家都有所发展？至少如果工会真能发挥作用，是能够给工人带来博弈支持的。而且商业本身就是追求共赢，过度打压工会，不利于长远发展。

# 22.黑社会是怎样赚钱的
黑社会是政府职能缺失后，补充政府的组织。一定是暴力集团，但是是否害民不一定。政府禁止自由贸易的产品往往意味着有高额利润，就会吸引胆子大的暴力团伙参与。在中国古代不让私人卖盐，要么官营，要么委托给大户给经营执照。官营一定做的不好，于是就一定存在私人贩盐。甚至那些承包的大户也会用执照掩护自己贩卖私盐。因为这个生意根本不愁买家很赚钱。也是因为这么赚钱，政府才垄断。现在比如烟草也是如此。一年中国烟草生意有上万亿的收入，而烟草的种植生产非常廉价。
在一些情况下如果政府治理不利，会引入底层百姓会自发引入黑社会来维护当地治安。在当下中国一般不会有这么嚣张的黑社会了，不过官商勾结，用黑社会当白手套，在过去几十年尤其拆迁问题上非常突出。m民主能不能遏制黑社会，我觉得不能。美国够民主了吧，经济够强大了吧，照样遍地黑帮。南美国家政府不强国家不强也是如此。

# 23.掠夺性策略的利益关系
强势政府给百姓带来的伤害大于黑社会。一种情况是政府足够强大剿灭黑社会，但是必然夹带大量冤假错案。比如汉武帝打压游侠。概率更大的是另外一种，就是本地的官员跟黑社会融合，那就完全暗无天日，而且政府权力已经很大了，没有任何制约，比纯黑社会更可怕。

以前的出租车，由于政府管制垄断，只给少数出租车公司牌照可以运营，那么民众花钱多获得的服务差，随着私家车的增加，就会出现黑车，便宜但是没有正规营业执照。但是百姓还是原因用。因为出租车行业被政府吸走了大量资金。当时政府打压黑车产业，可问题是需求在，利润在，打压的性价比不高。像以前的盐也是如此。政府通过这些垄断获取这么多的钱如果用于民生也好，现实却是修陵墓，建后宫，自己享受去了。因为没有监管啊，想怎么花就怎么花，花完了就加税。现在的社保不也是如此，取之尽锱铢，用之如泥沙。所以作为原子化的普通人一定要成立代表自己的组织才有力量，可是官方不允许成立这样的组织。黑社会从各个方面来讲都是不可避免的，相比较而言，依赖于官僚系统合作的黑社会占据的社会资源和存活一定是更好。民众的组织容易被分化瓦解。

# 25.改革开放三十年的社会进化
当时还在推动给媒体更大的自由度，可是现在任何内容都需要审核。已经没有相对独立和自由的媒体了。资本整体上还是推动民主化了，因为只有民主法治，资本的长远利益和最关心的安全问题才能得到解决。相反通过巴结权贵或者贿赂官员，一旦官员出了问题或者走了，每一次都是巨大的变数。
